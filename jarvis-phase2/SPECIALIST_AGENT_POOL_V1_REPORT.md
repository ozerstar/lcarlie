# Specialist Agent Pool V1

## Scope

Additive, merge-ready specialist capability layer. No runtime trigger, service,
database, firewall, provider, Research Controller, Data Fabric, or Web Console
change is included.

## Architecture

- Twenty L'CARLIE roles are registry metadata, not resident processes.
- Nine capability families share a deterministic evidence-bearing contract.
- Routing selects the minimum sufficient primary set.
- Independent primary specialists are parallel-compatible with bounded concurrency.
- The fixed order is primary analysis, evidence fusion, Red Team, Strategy, and
  Managing Director synthesis.
- Every final result is `PROPOSED`; external actions remain zero.

## Data and research boundaries

Company data is available only through named Company Memory readers. Missing
contracts return `DATA_UNAVAILABLE`; fixture or invented business data is never
substituted. Research specialists emit a disabled `fresh_research_source`
request compatible with Research Controller V1, but do not execute it.

The integration mapping uses the current Data Fabric allowlist directly:
`sales_orders`, `sales_items`, `ecommerce_profitability`, `ecommerce_price`,
`ecommerce_funnel`, `advertising_performance`, `advertising_spend`,
`crm_customers`, `crm_unanswered`, `operations_shipments`, `open_work`, and
`system`. GA4/site traffic, real inventory, and daily margin remain explicit
missing-data gaps.

## Deterministic-first policy

Routing, context isolation, confidence, evidence fusion, contradiction checks,
cache keys, ordering, and benchmark metrics use local rules and statistics.
Model calls are zero.

## Deterministic benchmark

For the requested sales, e-commerce, advertising, CRM, and operations fixture,
minimum routing selects eight specialists (five domain specialists plus Red
Team, Strategy, and Managing Director) instead of twenty. That is a 60%
specialist reduction, with five context units instead of twenty and four
dependency-stage work units instead of twenty, while preserving all requested
domain coverage. Both paths have zero model calls; the routed path also avoids
unrelated data retrieval.

## Rollback

No deployment is performed. Remove or revert the additive commit; no database,
service, or runtime rollback is required.
