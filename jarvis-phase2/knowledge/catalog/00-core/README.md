# 00-core

## Amac
Tum katalog disiplinlerinin paylastigi calisma kurallari: kanit
standardi, durum ayrimi, olcum-yargi siniri.

## Bu klasoru okuyan roller
- Butun capability'ler (C01-C15, HUMAN)

## Icerik
- Kanit standardi ve UNKNOWN politikasi
- Durum ayrimi sozlugu
- Olculebilir / yargisal siniri

## Guncelleme politikasi
Calisma kurali degistiginde. Nadiren.

## Kural
Bu klasordeki hicbir madde kaynaksiz olamaz. LLM'in kendi
uretttigi tasarim gorusu kanitlanmis kural olarak yazilmaz;
boyle bir madde `source_type` alanini dolduramaz ve
`items.json` dogrulamasindan gecemez.
