# 06-typography -- kabul ve ret

## Kabul (deterministik)
- Punto >= 5.5 pt (hicbir metin), govde >= 8.5 pt
- Guvenli alan ihlali = 0
- Metin carpismasi = 0
- Kullanilan fontlarin hepsi gomulu
- Kaynak fontlarda Turkce glif kapsamasi tam

## Uyari (durdurmaz)
- Kisa son satir (dul vekili)
- Satir uzunlugu ust siniri asimi
- Kullanilmayan gomulmemis font kaydi
