# F3 provider adapters

F3 adds isolated adapters for Claude, OpenAI, and a future OpenAI-compatible local endpoint.

The adapters are installed but disabled. No provider credential exists on the server and the active worker continues to use only FakeProvider adapters. Tests inject an in-memory FakeTransport and make zero HTTP calls.

Local endpoints require an operator-defined host allowlist. Model output cannot select a URL, HTTP method, SQL statement, shell command, or action.
