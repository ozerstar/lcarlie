# F5 controlled execution gateway

F5 adds database-enforced dual approval, atomic execution leasing, and a one-shot action worker. Only `REQUEST_HUMAN_REVIEW` has execution enabled, and its fixed FakeExecutor performs no external call.

WhatsApp, Meta, Wix, price, payment, publishing, shell, SQL, arbitrary HTTP, and arbitrary URLs remain non-executable. Critical actions require two distinct human identities and still have no enabled handler.
