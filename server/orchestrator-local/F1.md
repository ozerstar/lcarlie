# F1 one-shot worker

The worker connects with the dedicated `ai_orchestrator_worker` LOGIN, which is `NOINHERIT` and may set only `ai_reader` or `ai_writer`.

It runs once, claims at most one task, reads a bounded deterministic context, calls only `FakeProvider`, validates the proposal, writes only `PROPOSED` through F0-B functions, and records an audit attempt.

No scheduler, service, real provider, HTTP client, action gateway, or sales-system integration is enabled.
